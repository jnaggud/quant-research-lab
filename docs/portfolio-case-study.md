# Quant Research Lab — portfolio case study

**Role:** Python and Pine Script development, quantitative research tooling, data pipelines, and dashboard implementation.

## Project

A research toolkit that connects strategy development to execution checks and risk analysis. The system includes Python backtesting, TradingView parity tooling, Pine Script variants, data ingestion utilities, and an interactive browser dashboard.

## Engineering focus

- Model completed-bar signals, next-bar entries, gap-aware exits, commissions, and slippage.
- Test feature causality and account for open-position mark-to-market changes.
- Preserve research checkpoints, rejected variants, and dated validation reports.
- Separate licensed input data from reproducible source and synthetic demo fixtures.
- Make the dashboard installable independently and run automated checks in GitHub Actions.

## Short portfolio description

Built a Python and Pine Script quantitative research toolkit with TradingView execution-parity checks, walk-forward experiments, portfolio stress testing, and interactive dashboards. Added reproducible setup, automated tests, and a synthetic-data demo that runs without paid market data or API credentials.

**Skills:** Python, Pine Script, Flask, JavaScript, pandas, NumPy, quantitative research, data engineering, automated testing.
