# Portfolio walkthrough

**Title:** Algorithmic Trading Research Lab: Python & Pine Script

The 75-second captioned walkthrough uses captures of the working synthetic demo. It shows the interface and its controls; the public repository contains the broader research and Pine Script implementation.

## Sequence and narration script

| Time | View | Narration |
| --- | --- | --- |
| 0–12.5s | Research studio | This is Algorithmic Trading Research Lab, a Python and Pine Script toolkit for turning trading ideas into reproducible experiments. This dashboard runs on synthetic bars and an artificial trade ledger. |
| 12.5–25s | Horizon and path controls | The interactive studio lets you change the simulation horizon and number of paths. It provides a visual way to explore model assumptions alongside the underlying research. |
| 25–37.5s | Shock scale | Increasing the shock scale changes the scenario paths and their measured fragility. These are simulated scenarios, not forecasts or evidence of a profitable strategy. |
| 37.5–50s | Regime and decision view | The dashboard exposes regime scores and decision attribution. Synthetic inputs keep the posture at observe only, and the interface makes the model's limitations visible. |
| 50–62.5s | Trader statistics | Trade analysis includes net results, drawdown, outcome distributions, sleeve attribution, and the closed-trade ledger. The negative demo results are artificial and illustrate the reporting interface. |
| 62.5–75s | Repository and validation | The public source includes Pine Script strategies, Python research pipelines, execution-parity checks, automated tests, and dated validation reports. These components demonstrate work I can adapt to a client's documented requirements. |
